# Selenium 8 种元素定位方式（Day9）

> 2026-08-27 练习完成：`LocatorPractice.java` + `testpages/login.html`（本地练习页）
> 运行验证：8 种定位 + NoSuchElementException 全部通过

## 一、8 种定位方式对照表

| # | 方式 | 语法示例 | 适用场景 | 优先级 |
|---|------|---------|---------|--------|
| 1 | `By.id()` | `By.id("username")` | id 页面唯一，最稳定 | ⭐⭐⭐ |
| 2 | `By.name()` | `By.name("password")` | 表单元素（老项目常见） | ⭐⭐ |
| 3 | `By.className()` | `By.className("btn-primary")` | **只能传一个类名**，多类名会报错 | ⭐ |
| 4 | `By.tagName()` | `By.tagName("button")` | 页面只有一个某标签时 | ⭐ |
| 5 | `By.linkText()` | `By.linkText("关于我们")` | 链接完整文本，**只适用于 `<a>`** | ⭐⭐ |
| 6 | `By.partialLinkText()` | `By.partialLinkText("联系")` | 链接文本模糊匹配 | ⭐ |
| 7 | `By.xpath()` | `By.xpath("//input[@placeholder='请输入用户名']")` | 最强大：按文本/层级/索引/属性组合 | ⭐⭐⭐ |
| 8 | `By.cssSelector()` | `By.cssSelector("input[name='password']")` | 简洁，语法类似前端 CSS | ⭐⭐⭐ |

## 二、定位优先级（面试高频题）

> **面试问：你平时最常用哪几种定位？为什么？**

回答思路：**id > cssSelector > xpath > 其他**

1. **id 优先**：页面唯一、稳定，前端有约定时 id 不会变
2. **cssSelector**：语法简洁、比 xpath 快（浏览器原生支持）
3. **xpath**：功能最强，动态属性/无 id/层级深时用它
4. 链接类的 linkText：专门测导航/友情链接时用

## 三、常用 XPath 语法速查

| 语法 | 含义 | 示例 |
|------|------|------|
| `/` | 子节点（绝对路径） | `/html/body/div/form` |
| `//` | 任意层级（相对路径） | `//input` |
| `*` | 任意标签 | `//form/*` |
| `[@属性='值']` | 属性定位 | `//input[@placeholder='请输入用户名']` |
| `[n]` | 第 n 个（从 1 开始） | `//form/div[2]//input` |
| `contains(@class,'x')` | 类名模糊匹配（多类名神器） | `//button[contains(@class,'primary')]` |
| `text()='x'` | 按文本 | `//button[text()='登录']` |
| `//div[1]//input` | 后代（不管中间几层） | 表单内任意 input |
| `../` | 父节点 | `//input[@id='username']/..` |
| `@属性` | 取属性值 | `//input/@placeholder` |

**写 xpath 的套路**：F12 选中元素 → 右键 Copy → Copy XPath（Chrome 自动生成）。但要注意：Chrome 生成的往往是绝对路径，脆弱；自己写相对路径更稳。

## 四、常用 CSS Selector 速查

| 语法 | 含义 | 示例 |
|------|------|------|
| `#id` | id | `#username` |
| `.class` | 类名 | `.btn-primary` |
| `标签` | 标签 | `input` |
| `[属性='值']` | 属性 | `input[name='password']` |
| `标签.类` | 标签+类 | `button.btn-primary` |
| `空格` | 后代 | `form input`（form 里所有 input） |
| `>` | 直接子元素 | `form > div` |
| `:nth-child(n)` | 第 n 个子元素 | `div:nth-child(2)` |

## 五、实际踩过的坑

1. **className 不能写多个类名**：`class="btn btn-primary"` 只能传 `btn` 或 `btn-primary`，写两个就报错。cssSelector 可以写 `button.btn-primary`。
2. **linkText / partialLinkText 只对 `<a>` 链接有效**，按钮文本不能用它。
3. **tagName 只返回第一个匹配**：页面有多个 button 时，想拿第 2 个要用 `findElements().get(1)`。
4. **找不到元素时**：`findElement` 抛 `NoSuchElementException`；`findElements` 返回空列表**不抛异常**（判断元素是否存在用后者）。
5. 运行时出现的 CDP 警告（Chrome 版本和 Selenium devtools 不匹配）只是警告，不影响本次练习；以后升级 Selenium 版本解决。
