### 面试知识点（6 个考点）

| 考点 | 核心记忆 |
|------|---------|
| ① `==` vs `equals` | 基本类型比值，引用类型比地址，equals 比内容 |
| ① Integer 缓存 | -128~127 有缓存，超出范围 `==` 比地址 false |
| ① String 常量池 | `"a" == "a"` true，但 `new String("a")` 另开炉灶 |
| ④ 集合遍历删除 | 增强 for 删→抛 `ConcurrentModificationException`，for-i 删→记得 `i--` |
| ⑤ try-catch-finally | finally 一定执行，它的 return 会覆盖前面的 |
| ⑥ String 不可变 | `+` 拼接 = 新建对象（3个），循环拼接用 StringBuilder |
