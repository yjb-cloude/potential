# AI Agent 应用开发学习计划（原三线融合已调整）

> **调整日期**：2026-08-27
> **方向转变**：原计划"测试岗 + AI 辅助" → 现计划"AI Agent 应用开发"
> **原因**：对 AI Agent 方向更感兴趣，测试经验可作为差异化优势
> **面试策略**：用测试经验讲 AI Agent 项目（测试数据 → 训练数据，测试场景 → Agent 应用场景）

---

## 为什么选 Agent 开发

```
你的优势：
  测试经验（懂业务流程、数据验证、自动化思维）
      +
  Java 基础（后端开发能力）
      +
  AI Agent（最热门的技术方向）
      ↓
  差异化竞争力：既能写 Agent，又懂怎么测试它（很多人不会测 AI 应用）
```

**核心逻辑**：测试经验不是浪费，是 AI Agent 开发的**数据资产**和**场景理解力**。

---

## 学习路径（10 周计划）

```
第 1-2 周：Python 基础（你已有 Java 基础，学得快）
第 3 周：LLM 基础 + API 调用
第 4 周：Prompt Engineering（提示词工程）
第 5-6 周：LangChain 框架（Chain / Agent / Tool）
第 7 周：RAG（检索增强生成）
第 8 周：Function Calling + Tool Use
第 9 周：项目实战（智能问答 / 测试用例生成器）
第 10 周：部署 + 面试准备
```

**面试时间**：9月中旬 → 时间紧张，建议**第 6 周开始投简历**，边面试边深化。

## 技术栈

| 技术 | 用途 | 学习重点 |
|------|------|---------|
| **Python** | 主力语言 | 异步 async/await、类型注解、虚拟环境 |
| **LangChain** | Agent 开发框架 | LCEL、Chain、Agent、Tool、Memory |
| **OpenAI API** | LLM 调用 | Chat Completions、Function Calling |
| **ChromaDB** | 向量数据库 | 本地轻量，适合学习和原型 |
| **FastAPI** | Web API | 异步框架，部署 Agent 服务 |
| **Docker** | 容器化 | 打包部署 |

## 与测试经验的结合点

> 面试时这样讲：

| 测试经验 | 转化为 Agent 开发优势 |
|---------|---------------------|
| 懂业务流程 | 设计 Agent 工作流时知道真实业务怎么走 |
| 会写测试用例 | 能给 AI Agent 写评估用例（Eval） |
| 会自动化测试 | 能给 Agent 写自动化回归测试 |
| 懂数据校验 | 能验证 Agent 输出的质量和准确性 |
| 懂测试数据 | 知道怎么给 Agent 准备训练/测试数据 |

---

## 面试准备重点

**面试官问**："你为什么从测试转 AI？"

**回答**：
> "我发现 AI Agent 最缺的不是会调 API 的人，而是**懂业务场景、能验证输出质量**的人。我有测试背景，知道怎么设计评估用例、怎么验证 Agent 输出的正确性、怎么给 Agent 做回归测试。这些是纯开发人员不具备的。"
