## 面试项目展示（第 8 周时能讲）

**项目名称**：AI 测试用例生成器

**一句话介绍**：输入需求文档，AI 自动生成结构化测试用例

**技术栈**：Python + LangChain + OpenAI API + FastAPI

**亮点**：
1. 结合测试背景，知道怎么评估 AI 输出的质量
2. 用 Prompt Engineering 控制输出格式
3. 能给出实际的测试用例评估指标（覆盖率、边界检查完整性）

**面试话术**：
> "我之前做测试，发现写测试用例很耗时。所以用 LangChain 搭了一个 Agent，输入需求文档，它自动生成结构化用例。我用测试背景设计了评估标准，验证 AI 生成的用例质量。这个项目让我对 Agent 的规划能力和工具调用有了深入理解。"
